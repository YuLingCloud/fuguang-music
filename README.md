# 浮光音乐

一个自托管的在线音乐播放站：`node server.js` 起一个服务，浏览器打开即用。五平台（网易云 / QQ / 酷狗 / 酷我 / 咪咕）聚合搜索，七档音质无损优先自动降档，逐行歌词、歌单导入、队列持久化、四套主题（含深沉浸光影）。

## 快速开始

```bash
node server.js          # 或 npm start，端口取 PORT，默认 3000
# 打开 http://localhost:3000
bash watchdog.sh        # 可选：后台守护，进程退出每 5 秒自动拉起
```

---

## 一、这个项目是干嘛的

把各音乐平台的搜索、解析、歌词、封面收拢到一个自己的网页里：站内直连各平台搜索接口拿结果，播放链接由洛雪（LX）社区音源脚本竞速解析，服务端统一代理音频流。数据不落库、缓存播完即删，仅供个人学习研究。

## 二、功能怎么用

| 功能 | 操作 |
|---|---|
| 搜索 | 顶部搜索框输入关键词；左侧下拉切音源（全部 / 网易 / QQ / 酷狗 / 酷我 / 咪咕）；结果分「单曲 / 专辑 / 歌单」三个标签 |
| 播放 | 点列表行即播；底部播放条控制上一首 / 播放 / 下一首 / 循环模式；顶边进度条可拖拽 |
| 音质 | 点底部 `FLAC` 徽章弹七档（Master / Atmos+ / Atmos / Hires / Flac / 320K / 128K），取不到自动降档并提示 |
| 歌词 | 底部栏内嵌当前句；点歌词按钮进沉浸页（黑胶唱片 + 逐行滚动，点歌词行跳转进度） |
| 歌单导入 | 侧栏「导入歌单」粘贴网易云 / QQ / 酷狗 / 酷我歌单链接，整单入队 |
| 队列 | 侧栏「队列」查看 / 清空；单曲 / 列表循环 / 随机；刷新页面队列不丢 |
| 主题 | 侧栏「主题设置」四主题：浅·极简 / 浅·清新 / 深·通透 / 深·沉浸（深灰底板 + 随机跳动白色光点） |
| 背景 / 横屏 | 侧栏「换背景」换背景图；移动端「横屏」锁方向，沉浸页可切明暗 |
| 快捷键 | `空格` 播放/暂停，`Esc` 收起沉浸页 |
